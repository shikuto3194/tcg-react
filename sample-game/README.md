# 星環の庭 — The Starlit Gardens

四季の幻想庭園で精霊と星灯を集める、2人用のオリジナルサンプルです。40種・4庭、精霊24種と術式16種。各庭10種を2枚ずつ組んだ20枚のスターターをアプリに同梱します。想定プレイ時間は約15分ですが、対人テストとバランス調整は未実施です。

## 世界とカード

翠芽（春／翡翠）、燈火（夏／朱金）、琥珀（秋／赤銅）、月白（冬／藍銀）の庭が、白い石造建築と星の光でつながる世界です。動物や幻獣、植物、道具、風景に加え、人型は8種。兎人の案内人、庭姫、猫術師、獅子姫、菓子職人、梟司書、侍女、竜姫を配し、表情・衣装・視線で親しみやすさを出しています。

構図は寄りの肖像、座り姿、横顔、俯瞰、低い視点、遠景、接写、斜めの動作を混ぜています。カード名・コスト・種類・効果・フレーバー・番号・力は生成画像に含めず、文字レイヤーとして組みます。

## 遊び方

必要なもの：1人20枚のデッキ（同名2枚まで／庭の混在可）、星灯・光を数えるカウンター。アプリ上の採用上限は汎用機能の方針どおり初期なしなので、このサンプルルールを自動で強制しません。

1. 山札を混ぜて5枚引く。星灯0、光の上限0から開始。先手を決める。
2. 自分の番の初めに精霊をすべて起こす。光の上限を1増やし（最大6）、光を上限まで補充して1枚引く。先手の最初のドローは省略。山札が空なら引く代わりに相手の星灯を1増やす。
3. 光をコスト分払ってカードを使う。精霊は眠った状態（横向き）で場に出し、登場時効果を解決する。場は5体まで。術式は効果を解決して捨てる。
4. 起きた精霊を眠らせ、「星灯を1得る」か「相手の精霊1体と力比べ」を行う。力比べは力が小さい方を捨て、同値なら両方捨てる。眠った相手も対象にできる。
5. 行動は光や起きた精霊がある限り好きな順で行える。番の終わりに光の残りを0にし、手札が7枚を超えた分を捨てて交代する。星灯が7以上になった人の即時勝利。

対象がなければ効果は何もせず終了。精霊を起こす効果により、登場した番や行動後でも行動できる。手札に戻った精霊の状態はリセットする。カードを引く効果でも、山札が空なら不足1枚ごとに相手の星灯を1増やす。効果は本文の順に処理し、ゲームが終わったら以降の処理を行わない。

デッキ管理・印刷までがアプリの役割です。自動対戦やルールエンジンは含めません。

## 制作・再生成

| ファイル | 用途 |
| --- | --- |
| cards.csv | 40枚の制作元データ。IDは1〜40、実行用IDは10001〜10040 |
| card.html | 編集可能なHTML。内部のSVG／CSSが枠・文字・原画の配置を定義 |
| art/01.webp〜40.webp | 文字なしの生成原画。品質94で保存 |
| art-prompts.json | 各原画の最終生成プロンプトと構図 |
| ../scripts/build-sample.mjs | 同じSVGをSharpで描画し、完成PNGと実行用データを生成 |
| ../images/starlit/01.png〜40.png | 枠・文字・絵を合成した完成カードPNG、756×1056px、63×88mm向け |
| ../src/cardData.js | CSVから生成した実行用カード情報 |

```sh
npm run sample:build
npm run check
```

原画はOpenAI imagegenで制作。01を世界観・仕上げの参照にし、各カードは個別に生成しています。旧ゲームの画像やカード情報を素材として使用していません。元の生成PNGは生成ツール側に残し、リポジトリではWebP原画と完成PNGを管理します。

日本語組版には端末のYu Gothic／Meiryo／Noto Sans CJK JP等が必要です。フォントファイルは同梱していません。確認した生成環境はWindows。Linux等で再生成するとフォント差により字形・改行の見え方が変わる場合があるため、完成PNGを必ず目視してください。通常ビルドでは再生成せず、確定したPNGを同梱します。

cards.csvは制作専用で、アプリの読込CSVとは列が異なります。アプリのカード取込では、ゲームごとに設定した項目に対応するCSVを使用します。アプリ内でカード情報を編集しても、既に焼き込まれたPNGの文字は変わりません。サンプル原稿を修正する場合はCSVから再生成します。

## 目視確認記録（2026年10月6日）

生成原画40枚を確認し、完成カード40枚を4セットの一覧で再確認しました。人型の指・腕と小物、四足獣の脚、鳥の翼、角・尻尾、鏡・砂時計等の形状をチェック。見える範囲に明確な手足の重複や接続破綻は見当たりませんでした。構図が繰り返されていた鹿は遠景に作り直し、8種を人型へ変更しました。

完成PNGは顔、角、効果文、フレーバー、番号を照合。耳・翼を優先する画像は上端基準で配置し、肖像の一部や動きのある翼先は意図的な画面外への切れを許容しています。カード035は翼の上端が余計に切れないよう配置を補正。自動検査で全画像の寸法・原画・CSV対応・画像領域の欠落を確認しています。
