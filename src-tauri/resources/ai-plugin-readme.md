# TCG マネージャー — このPC用プラグイン

このプラグインを作成したWindows PCで使います。TCG マネージャーは開いたままにしてください。

## Claude Cowork

1. ClaudeのPCアプリでClaude Coworkを開き、「カスタマイズ → プラグイン」から保存したZIPを追加します。
2. TCG マネージャーの「設定 → AI連携」で「AIとの接続を開始」を押します。
3. 「作業を頼む文章をコピー」を押し、設定画面を閉じます。
4. Claude Coworkの新しい会話に貼り付け、末尾の「依頼：」にしてほしいことを書いて送信します。

ローカルMCPプラグインを実行できるPC環境が必要です。通常のChatやクラウドだけの実行、Androidではこのプラグインを使えません。組織でローカルMCPが禁止されている場合は管理者に確認してください。

## ChatGPT Work / Codex

TCG マネージャーの「設定 → AI連携」で「Codex / ChatGPT Work（プラグイン）」を選び、「プラグインの導入画面を開く」を使ってインストールします。PCを実行先にした新しい会話で使ってください。既存の「Codexに接続を登録」と併用すると同じツールが重複するため、どちらか一方を使います。

## 接続の仕組み

`.mcp.json`はインストール済みの`tcg-local.exe --mcp`を起動します。実際の保存場所を含むため別PCへの配布には使わず、そのPCのTCG マネージャーから作成し直してください。Node.jsの導入は不要です。

接続キーやカードデータはプラグインへ含めません。Windowsの接続ファイルはユーザーフォルダ内の`.tcg-manager/ai-connection.json`です。中継は要求ごとに読み直します。以前の標準AppDataパスを参照するプラグインは、更新後のexeが新しいパスへ読み替えます。独自の保存先は読み替えません。

最初に`tcg_status`で対象ゲームを確認します。検索の`fields`は`tcg_settings_get`の`fieldKeys`と`labels`で対応を確認し、表示順から`item1`などを推測しません。カード・デッキ・戦績の操作はユーザーが依頼した範囲で行い、更新後は読み直して結果を確認してください。

接続できない場合は、アプリの待受、MCP認証・初期化、ツール一覧の取得、会話でのツール公開を分けて確認します。「AIとの接続を停止」が表示されていれば待受は開始済みです。根拠なく停止・開始を繰り返させず、「接続できないとき → 接続ファイルを確認」とAI側の起動エラーを確認してください。`tcg-local.exe --mcp-diagnose`は接続ファイル・初期化・一覧・tcg_statusを読み取りだけで検査し、キーやゲーム内容を表示しません。この診断の成功と、AIの会話でツールが使えることは別です。

`CONNECTION_FILE_MISSING/UNREADABLE/INVALID`はファイル、`APP_UNREACHABLE`は待受先、`AUTH_REJECTED`は認証、`INITIALIZE_FAILED`はMCP初期化、`TOOLS_UNAVAILABLE`は一覧取得の失敗です。更新の応答が不明なら同じrequestIdと引数で再試行し、結果を読み直します。権限・承認設定を変更したり、接続を外部公開したりしないでください。
